# Evaluating LLM-Contaminated Crowdsourcing Data Without Ground Truth

This repository contains the **code and data** for the NeurIPS 2025 paper:

> **Evaluating LLM-Contaminated Crowdsourcing Data Without Ground Truth**  
> *Accepted at NeurIPS 2025*

The project studies how to evaluate and diagnose crowdsourcing data that has been **contaminated by LLM-generated or low-effort labels**, **without access to ground truth**, and provides both theoretical and empirical validation across multiple domains.

---

## Repository Structure

The repository is organized by **dataset / application domain**. Each top-level folder corresponds to one experimental setting in the paper.


### Overview of folders

| Folder | Description | Paper Reference |
|------|------------|----------------|
| `Preference_labeling/` | Preference labeling task with human + LLM-generated labels | Main paper |
| `Toxicity_labeling/` | Toxicity annotation task with LLM contamination | Main paper |
| `Peer_review/` | Peer-review style, high-dimensional labeling task | Appendix F |

---

## Main Experimental Datasets

### `Preference_labeling/` and `Toxicity_labeling/`

These two folders contain **all code and data for the main experimental results** in the paper.

Each folder has the same internal structure:

#### Key files and_toggle their roles

- **`Assumption_test.ipynb`**  
  Implements the experiments in **Section 5.2** of the paper.  
  This notebook tests the modeling assumptions underlying our ground-truth-free evaluation framework.

- **`Detect_low_effort_workers.ipynb`**  
  Implements the experiments in **Section 5.3** of the paper.  
  This notebook demonstrates how the proposed framework can be used to **detect synthetic low-effort workers** without ground truth.

- **`<LLM-generated labels folder>/`**  
  Contains **synthetic labels generated by various LLMs**.

---

## High-Dimensional Generalization

### `Peer_review/`

This folder contains the **code and data for Appendix F**, which studies the generalization of our framework to **high-dimensional, structured data**, inspired by peer-review settings.

---

## Reproducibility

- All experiments are implemented in **Python** using Jupyter notebooks.
- Notebooks are self-contained and can be run independently within each folder.
- Large intermediate outputs are not required to reproduce the reported results.

We recommend running notebooks in the order described in the paper sections.
